# Global Passport · 环球护照（旅行模拟游戏）

将「全球通关成就墙」升级为**可玩的旅行模拟游戏**：选择你的护照出生，环球移动、办理签证、盖入境章、收集贴纸，完成 32 项史诗级旅行成就。

## 🎮 玩法

- **选护照出生**：11 种身份（中国 / 台湾地区 / 美 / 日 / 俄 / 法 / 德 / 英 / 希腊 / 意大利 / 蒙古），中国护照可选福建 / 广东 / 海南户籍
- **环球移动**：SVG 航线图，飞机 / 陆路 / 海路 / 转机过境四种方式
- **签证系统**：免签直达、落地签、签证中心申请（审批天数 + 成功率）、历史签证商店（苏联 / 民主德国 / 联邦德国 / 中华民国 1912-1949 / 法兰西第四共和国）、偷渡硬闯
- **护照贴纸**：4×3 贴纸网格可点击交换——把民主德国 / 联邦德国贴纸摆成左右相邻解锁「柏林墙」，把朝鲜 / 韩国贴纸摆成上下相邻解锁「三八线」
- **32 项成就**：7 大系列（旅行家 / 冷战风云 / 全球冲突 / 不走寻常路 / 幻想时刻 / 精罗落泪 / 探索时代），全部可达成
- 进度自动保存于浏览器 localStorage

## 🚀 本地运行

直接双击打开 `index.html` 即可，单文件、零依赖、无需构建。
